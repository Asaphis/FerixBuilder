# Web/frontend

**Web/frontend** is FerixBuilder's public and customer-facing application area. It owns the marketing experience, authentication entry, onboarding, project customer dashboard, preview/revision interfaces, billing, delivery downloads, and customer support surfaces.

The current Vite application is served from this directory through the compatible `client` path at the repository root. New public and customer pages should be placed under `Web/frontend/src/pages/`, with reusable customer-facing components under `Web/frontend/src/components/`.
